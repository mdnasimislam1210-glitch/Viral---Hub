# 🔥 Viral Video Hub & Motion News Portal

A sleek, high-conversion web application designed for viral content sharing, traffic redirection, and monetization.

### ✨ Features
* **Motion Graphics UI:** Futuristic dark glassmorphism design optimized for mobile and social traffic.
* **Secure Hidden Admin Panel:** Accessible via a discreet hidden gear icon (⚙️) with password protection.
* **Dynamic Video Manager:** Easily add, manage, and delete viral video posts via LocalStorage.
* **Multi-Ad Slot Manager:** Paste custom ad network scripts (Adsterra, Monetag, Google AdSense, etc.).
* **2-Step Monetization Logic:** 1st click triggers pop/interstitial ads, 2nd click directs users to the source video (Google Drive / Cloudflare).
* **Social Footer:** Quick-access glowing buttons for Facebook, Instagram, and Telegram.
